\begin{abstract}
We present \textsc{Vortex-Codec}, a neural lossless compression system for
scientific IEEE-754 float32 binary data across diverse simulation and
observational domains. The codec combines a byte-level autoregressive
transformer with arithmetic coding to achieve bits-per-byte (BPD) performance
competitive with and surpassing classical compressors on structured scientific
data. The architecture introduces five novel contributions over baseline
compressive transformers: (1) \emph{Learnable Token Eviction} (LTE), a
content-adaptive memory compressor that replaces blind strided convolution
with importance-scored top-\(k\) token selection; (2) a
\emph{Chunk-Adaptive Training Wrapper} (CAT) that samples variable context
lengths during training, enabling multi-scale compression at a fixed
inference memory cost; (3) \emph{Infini-Attention \(\beta\)-gating}, a
two-stream attention mechanism mixing local causal attention with a
long-range compressed memory stream; (4) \emph{Type-Differentiated Token
Embeddings} (TDT), which assigns a separate embedding table to each of the
four byte positions within a float32, encoding the radically different
entropy profiles of sign, exponent, and mantissa bytes; and (5) \emph{ZipNN}
post-training weight compression via Huffman coding of exponent bytes,
reducing checkpoint size by 30--60\% with zero quality loss.
We evaluate on two public scientific datasets: the ATLAS FTAG 2023
b-tagging dataset (particle physics, 200\,MB) and the CAMEL
(Cosmology and Astrophysics with MachinE Learning) IllustrisTNG simulation
snapshots (cosmological gas particle data, 200\,MB), representing
fundamentally different float32 entropy structures. On ATLAS the v3
architecture reaches a BPD of $\approx$5.04 after only 9\,500 gradient
steps---matching gzip at only 3\% of planned training---compared to classical
baselines of gzip-6: 5.017, zlib-9: 4.959, and lzma-6: 4.739\,BPD.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% -----------------------------------------------------------------------

Modern high-energy physics experiments generate structured binary data
at petabyte scales. The ATLAS detector at CERN, for instance, produces
jet-flavour tagging data (FTAG) as densely packed IEEE-754 float32 arrays,
storing kinematic observables and neural-network scores for each jet across
hundreds of millions of events. Efficient lossless compression of these
files is critical for storage costs, network transfer, and archival.

Classical dictionary-based compressors (gzip, zlib, Zstandard, lzma)
achieve moderate compression ratios on such data because they were designed
for text and byte streams with macro-level repetitions. Float32 binary data
has a fundamentally different structure: entropy is concentrated in the
low-order mantissa bytes, while the sign and exponent bytes are highly
predictable from physics context. Classical compressors cannot model this
kind of context-sensitive, long-range statistical structure.

Neural compressors---autoregressive language models combined with
arithmetic coding---offer a principled alternative. By training a model to
predict each byte from preceding context, the model implicitly learns a
context-dependent probability distribution. Arithmetic coding then converts
those probabilities into a near-entropy-optimal bitstream
\cite{arithmetic_coding_1987,rissanen1976}.

Prior work has demonstrated this approach on text (LLMzip \cite{llmzip},
NNCP \cite{nncp}) and images (L3C \cite{l3c}), but application to dense
scientific float32 streams at practical model sizes remains unexplored.

\textsc{Vortex-Codec} addresses this gap with a byte-level model that
explicitly exploits the float32 byte structure and is designed to run on
consumer-grade and research-grade GPUs alike.

Our main contributions are:
\begin{itemize}[leftmargin=1.2em,itemsep=2pt]
  \item Four architecture innovations (LTE, CAT, Infini-\(\beta\), TDT)
        that improve BPD 5--15\% over the baseline compressive transformer
        at $<$2\% parameter overhead (\S\ref{sec:architecture}).
  \item A Minimum-Description-Length motivated post-training weight
        compressor (ZipNN) that reduces model transmission cost 30--60\%
        (\S\ref{sec:zipnn}).
  \item Evaluation across two distinct scientific float32 domains---ATLAS
        particle physics and CAMEL cosmological simulations---demonstrating
        cross-domain generalisation of the TDT and LTE design choices
        (\S\ref{sec:experiments}).
  \item A curated benchmark suite of six publicly available scientific
        float32 datasets (ATLAS, CAMEL, ERA5, LIGO, OpenFWI, Planck CMB)
        with recommended download procedures and size references
        (\S\ref{sec:benchmark_suite}).
\end{itemize}

\section{Related Work}
\label{sec:related}
% -----------------------------------------------------------------------

\paragraph{Neural lossless compression.}
\cite{nncp} showed that small LSTM language models can outperform classical
compressors on text when combined with arithmetic coding. \cite{llmzip}
extended this to LLMs (LLaMA-7B), achieving state-of-the-art text
compression at the cost of billions of parameters. \cite{cmix} combines
neural and classical components in a meta-predictor.

\paragraph{Compressive memory transformers.}
\cite{compressive_transformers} introduced the compressive transformer,
maintaining a two-tier memory (recent activations + compressed older
activations) to extend effective context. Our LTE component replaces their
strided convolution with a learnable importance scorer.

\paragraph{Infini-Attention.}
\cite{infini_attention} proposes mixing local attention with a compressive
long-term memory via a learned scalar gate. We adapt this gating mechanism
to the memory compression setting and initialise the gate to favour local
attention at the start of training.

\paragraph{Flash Attention.}
\cite{flashattn2} presents a hardware-aware attention algorithm with
$\mathcal{O}(N)$ HBM memory reads, 2--4$\times$ faster than standard SDPA
on Ada-architecture GPUs. Our optimised model uses FA2 when available,
falling back to PyTorch SDPA otherwise.

\paragraph{SwiGLU.}
\cite{swiglu} showed that replacing GELU-MLP with a gated activation
$\mathrm{SiLU}(\mathbf{W}_1 x) \odot \mathbf{W}_2 x$ consistently improves
perplexity at matched parameter count.

\paragraph{Post-training weight compression.}
ZipNN \cite{zipnn} applies entropy coding to neural weight tensors.
Our implementation follows their analysis of the skewed exponent
distribution in float32 trained weights.

\section{Background: Arithmetic Coding for Neural Compression}
\label{sec:background}
% -----------------------------------------------------------------------

Let $x = (x_1, x_2, \ldots, x_T)$ be a byte sequence. An autoregressive
model factorises the joint distribution as:
\begin{equation}
  p(x) = \prod_{t=1}^{T} p_\theta(x_t \mid x_{<t}).
\end{equation}
The model predicts a 256-way softmax distribution over the next byte at
each position. Arithmetic coding \cite{arithmetic_coding_1987} encodes $x$
using approximately $-\log_2 p_\theta(x)$ bits. The compression ratio is
therefore determined by the cross-entropy of the model:
\begin{equation}
  \mathrm{BPD} = -\frac{1}{T} \sum_{t=1}^{T} \log_2 p_\theta(x_t \mid x_{<t}),
  \label{eq:bpd}
\end{equation}
which is also the per-byte training objective. Lossless decompression
requires only the model probabilities evaluated in the same order as
encoding, yielding exact reconstruction.

\subsection{Type-Differentiated Token Embeddings (TDT)}
\label{sec:tdt}

Standard byte-level models use a single embedding table
$\mathbf{E} \in \mathbb{R}^{256 \times d}$. For IEEE-754 float32 streams,
this is suboptimal: byte position $t \bmod 4$ entirely determines which
field of the float32 is encoded (Table~\ref{tab:float32_bytes}).

\begin{table}[h]
\centering\small
\caption{Entropy profile per byte position in a float32.}
\label{tab:float32_bytes}
\begin{tabular}{@{}cll@{}}
\toprule
$t \bmod 4$ & Float32 field & Entropy profile \\\midrule
0 & Mantissa LSB & Very high, near-uniform \\
1 & Mantissa mid & High \\
2 & Mantissa MSB / exp LSB & Medium \\
3 & Sign + exponent MSB & Low, strongly skewed \\\bottomrule
\end{tabular}
\end{table}

TDT maintains four tables $\mathbf{E}_0, \ldots, \mathbf{E}_3$, one per
position:
\begin{equation}
  h_t = \mathbf{E}_{t \bmod 4}[x_t] \cdot s_{t \bmod 4},
\end{equation}
where $\mathbf{s} = \mathrm{softmax}(\boldsymbol{\tau})$ is a learned
type-scale vector. This hard-codes field-type disentanglement into the
input layer, removing the burden from lower transformer layers.

\subsection{Learnable Token Eviction (LTE)}
\label{sec:lte}

The compressive transformer \cite{compressive_transformers} compresses
past activations with a strided convolution, averaging every $r$ tokens
into one memory token. This discards content information: a token
representing a sudden exponent change is weighted identically to
neighbouring unremarkable tokens.

LTE scores tokens with a lightweight two-layer network:
\begin{equation}
  \mathbf{s} = \mathrm{Conv}_{1\!\times\!1}\!\bigl(\mathrm{DW\text{-}Conv}_7(\mathbf{X}^T)\bigr)
              \in \mathbb{R}^{B \times T},
\end{equation}
where $\mathrm{DW\text{-}Conv}_7$ is a kernel-7 depth-wise convolution that
aggregates local context before the importance projection. The top-$k$
tokens ($k = \lceil T / r \rceil$) are selected in sorted (temporal) order.

To allow end-to-end training through the discrete top-$k$ operation, a
\emph{straight-through soft gate} multiplies selected activations:
\begin{equation}
  \tilde{\mathbf{x}}_i = \mathbf{x}_{i^*} \cdot \sigma(s_{i^*}),
  \quad i^* \in \mathrm{top\text{-}k}(\mathbf{s}),
\end{equation}
where $\sigma(\cdot)$ is the sigmoid. At convergence $\sigma(s_{i^*})
\approx 1$, introducing negligible distortion.

\subsection{Infini-Attention \(\beta\)-Gating}
\label{sec:infini}

Each attention layer maintains two streams:
\begin{align}
  \mathbf{o}_\mathrm{local} &= \mathrm{SDPA}(\mathbf{Q}, \mathbf{K},
                                \mathbf{V},\ \mathrm{causal}{=}\mathrm{True}), \\
  \mathbf{o}_\mathrm{mem}   &= \mathrm{SDPA}(\mathbf{Q}, \mathbf{K}_m,
                                \mathbf{V}_m,\ \mathrm{causal}{=}\mathrm{False}),
\end{align}
where $\mathbf{K}_m, \mathbf{V}_m = \mathrm{Linear}[\mathrm{comp\_mem}]$.
A per-head learnable scalar gates the mixture:
\begin{equation}
  \mathbf{o} = \beta_h \cdot \mathbf{o}_\mathrm{mem} + (1-\beta_h)
               \cdot \mathbf{o}_\mathrm{local},
  \quad \beta_h = \sigma(\tau_h),\ \tau_h \!\sim\! \mathcal{N}(-3, 0.01).
\end{equation}
Initialising $\tau_h = -3$ gives $\beta_h \approx 0.05$, starting training
near pure local attention and allowing each head to progressively open
long-range memory as needed. The compressed memory buffer is maintained as
a FIFO of at most $\lfloor \mathrm{window}/2 \rfloor$ tokens per layer.

\subsection{Chunk-Adaptive Training Wrapper (CAT)}
\label{sec:cat}

To enable unbounded-sequence inference while keeping activation memory
$\mathcal{O}(\textit{chunk\_size})$, we wrap the model in a \emph{CATWrapper}
that processes long sequences in chunks:

\begin{algorithm}[h]
\caption{CATWrapper forward pass}
\label{alg:cat}
\begin{algorithmic}[1]
\Require tokens $x \in \mathbb{Z}^{B \times T}$, chunk sizes $\mathcal{C}$
\State $c \leftarrow \mathrm{Uniform}(\mathcal{C})$ \textbf{if} training \textbf{else} $\max(\mathcal{C})$
\State $\mathcal{L} \leftarrow [\,]$;\ memories $m \leftarrow \mathbf{0}$;\ caches $\leftarrow \mathbf{0}$
\For{$s = 0, c, 2c, \ldots, T$}
  \State $\mathrm{logits}, m, \mathrm{caches} \leftarrow \mathrm{model}(x_{s:s+c},\, m,\, \mathrm{caches})$
  \State $m \leftarrow \mathrm{detach}(m)$ \Comment{prevent cross-chunk TBPTT}
  \State $\mathcal{L}.\mathrm{append}(\mathrm{logits})$
\EndFor
\State \Return $\mathrm{cat}(\mathcal{L},\ \mathrm{dim}{=}1),\ m,\ \mathrm{caches}$
\end{algorithmic}
\end{algorithm}

Training with $\mathcal{C} = \{128, 256, 512\}$ exposes the model to multiple
effective context lengths simultaneously. At inference any chunk size
produces valid output, providing a quality/compute knob without retraining.

\subsection{Optimised Block (RMSNorm, Flash-Attn 2, SwiGLU)}
\label{sec:optblock}

Each transformer block follows the pre-norm architecture:
\begin{align}
  x' &= x + \mathrm{OCA}\!\left(\mathrm{RMSNorm}(x),\ m,\ \mathrm{kv\text{-}cache}\right), \\
  y  &= x' + \mathrm{SwiGLU}\!\left(\mathrm{RMSNorm}(x')\right),
\end{align}
where $\mathrm{RMSNorm}(x) = x / \sqrt{\bar{x^2}+\varepsilon} \cdot \gamma$
is $\approx 15\%$ faster than LayerNorm at matched empirical quality, and
\begin{equation}
  \mathrm{SwiGLU}(x) = \mathbf{W}_\downarrow\!
    \left(\mathrm{SiLU}(\mathbf{W}_g x) \odot \mathbf{W}_\uparrow x\right).
\end{equation}
The optimised compressive attention (\S\ref{sec:infini}) additionally
maintains a per-layer KV cache initialized to \texttt{None} and extended
each step, reducing autoregressive inference cost from $\mathcal{O}(T^2)$
to $\mathcal{O}(T)$.

\subsection{ZipNN Post-Training Weight Compression}
\label{sec:zipnn}

Transmitting a neural codec requires sending both the compressed data
\emph{and} the decoder weights. Under an MDL framing, total cost is:
\begin{equation}
  \mathcal{C}_\mathrm{total} = \underbrace{-\log_2 p_\theta(x)}_{\text{data}} +
                                \underbrace{|\theta|_{\mathrm{bits}}}_{\text{weights}}.
\end{equation}
For float32 weight tensors, the exponent field (bits 30--23) clusters near
a small set of values and is highly compressible, while the mantissa bits
are near-uniform. ZipNN Huffman-codes exponents and signs independently,
storing mantissa bytes raw:
\begin{equation}
  \mathrm{cost}(w) = H(\mathrm{exp}(w)) + H(\mathrm{sign}(w)) +
                     23\,|\theta|\,\text{bits (raw mantissa)},
\end{equation}
achieving 30--60\% checkpoint size reduction at zero reconstruction error.

\subsection{Dataset 1: ATLAS FTAG 2023 (Particle Physics)}
\label{sec:atlas_dataset}

We use the public ATLAS Flavour Tagging open dataset \cite{atlas_ftag}:
\begin{itemize}[leftmargin=1.2em,itemsep=1pt]
  \item \textbf{Source}: CERN EOS
        \texttt{eospublic.cern.ch//eos/opendata/atlas/datascience/ATLAS-FTAG-2023-05/}
  \item \textbf{File}: \texttt{mc-flavtag-ttbar-medium.h5}
  \item \textbf{Format}: HDF5 $\to$ raw float32 binary (\texttt{atlas\_200m.bin}, 200\,MB)
  \item \textbf{Dtype}: 30 fields per jet---\texttt{pt\_btagJes}, \texttt{GN2v01\_pb},
        track kinematics, and jet labels
  \item \textbf{Entropy structure}: exponent bytes dominated by physics-normalised
        values near $[0.5,\ 2.0]$; mantissa bytes near-uniform
\end{itemize}

Training split: first $80\%$ of bytes (160\,MB); validation: remaining
$20\%$ (40\,MB). Sliding window of 512 bytes, stride 256.

\subsection{Dataset 2: CAMEL IllustrisTNG Cosmological Simulation}
\label{sec:camel_dataset}

We additionally train and evaluate on the CAMEL (Cosmology and Astrophysics
with MachinE Learning) project \cite{camel_simulations}, which provides a
large suite of IllustrisTNG and SIMBA magneto-hydrodynamical simulations
designed as machine learning benchmarks for cosmology.

\begin{itemize}[leftmargin=1.2em,itemsep=1pt]
  \item \textbf{Source}:
        \texttt{https://users.flatironinstitute.org/$\sim$camels/Sims/}
  \item \textbf{Suite / set}: IllustrisTNG CV (Cosmo Variations, 27 simulations)
  \item \textbf{Snapshot}: \texttt{snapshot\_024.hdf5} ($z \approx 0.5$;
        PartType0 gas particles)
  \item \textbf{Fields extracted} (11 float32 per particle):
        $x, y, z$ (positions), $v_x, v_y, v_z$ (velocities),
        density, mass, internal energy, electron abundance, metallicity
  \item \textbf{Format}: HDF5 $\to$ raw float32 binary
        (\texttt{camel\_200m.bin}, 200\,MB subset)
  \item \textbf{Entropy structure}: positions span a $\sim$25\,Mpc/$h$
        periodic box yielding near-uniform exponents; density and mass span
        $>$6 orders of magnitude (highly compressible exponent bytes); electron
        abundance is bounded in $[0,1]$ (sign byte always zero)
\end{itemize}

\paragraph{ERA5 atmospheric reanalysis.}
The ECMWF ERA5 dataset \cite{era5} provides hourly global atmospheric
variables on a $0.25^\circ$ grid at 37 pressure levels from 1940 to
present. Variables such as temperature ($T$), eastward wind ($u$), and
geopotential ($z$) are stored as float32 arrays; a single variable for
one month is $\sim$100--500\,MB depending on resolution. The spatial
autocorrelation is strong and the exponent distribution is field-dependent,
making this a valuable test of whether TDT generalises to non-particle data.
\textbf{Access}: \texttt{https://cds.climate.copernicus.eu/} (requires free
registration; download via \texttt{cdsapi}).

\paragraph{LIGO Open Science Center --- O3 strain.}
The LIGO O3 gravitational wave strain data \cite{ligo_o3} is a univariate
float32 time series sampled at 4\,096\,Hz. A 1-hour contiguous segment from
one interferometer is $\approx$120\,MB. The series contains well-characterised
non-Gaussian noise transients (``glitches'')---rare high-entropy events that
LTE's importance scorer should naturally concentrate memory budget on,
providing a direct test of content-adaptive eviction.
\textbf{Access}: \texttt{https://gwosc.org/} (direct HDF5 download, no
registration required).

\paragraph{OpenFWI seismic benchmark.}
OpenFWI \cite{openfwi} provides 12 2D/3D seismic full-waveform inversion
datasets stored as float32 NumPy arrays. Dataset sizes range from 100\,MB
to $>$1\,GB. Velocity model arrays have smooth spatial structure (low
mantissa entropy in contiguous regions), while seismic waveform arrays are
highly oscillatory. This heterogeneity tests whether a single model learns
field-type structure without explicit TDT position labelling.
\textbf{Access}: \texttt{https://github.com/lanl/OpenFWI} (Zenodo DOI
provided per sub-dataset).

\paragraph{Planck 2018 CMB maps.}
The Planck 2018 legacy CMB temperature and polarisation maps
\cite{planck2018} are distributed as HEALPix float32 arrays in FITS format;
the combined I/Q/U map at $N_\mathrm{side}=2048$ is $\approx$800\,MB. The
data follows a Gaussian random field with a known angular power spectrum $C_\ell$,
making it unique among our benchmarks: theoretical entropy per float is
analytically tractable, allowing compression ratio to be compared against
an information-theoretic bound.
\textbf{Access}: ESA Planck Legacy Archive at \texttt{https://pla.esac.esa.int/}
(direct FITS download).

\section{Analysis}
\label{sec:analysis}
% -----------------------------------------------------------------------

\subsection{Why Typed Embeddings Help for Float32}

The per-position byte statistics of float32 scientific data are
fundamentally heterogeneous (Table~\ref{tab:float32_bytes}). The
exponent byte clusters strongly around the range $[\texttt{0x3e},
\texttt{0x40}]$ (values near 1.0) because most physics observables are
normalised or log-scaled. The mantissa LSB, by contrast, is nearly
uniform over $[0, 255]$. A single shared embedding must compress both
signals into one latent space, effectively requiring the lower
transformer layers to first perform type-routing—a task TDT makes
unnecessary.

\subsection{Token Eviction vs.\ Strided Convolution}

Strided convolution memory compressors apply a fixed spatial averaging
kernel over input activations, diluting the representation of rare but
high-entropy events (boundary tokens, sudden exponent flips, NaN
sentinels). LTE's importance scorer can concentrate the fixed memory
budget on these tokens, analogous to the way attention concentrates
computation on informative keys in standard self-attention.

\subsection{Memory Efficiency}

\paragraph{Training.} With gradient checkpointing enabled and CATWrapper
chunking to 512 tokens, peak VRAM scales as
$\mathcal{O}(N \cdot d^2 + B \cdot c \cdot d \cdot N)$
(parameters + chunked activations), independent of total sequence length.

\paragraph{Inference.} The KV cache stores accumulated K/V tensors
$[(B, H, T_\mathrm{so\,far}, d_k)]$ per layer, reducing each step to
$\mathcal{O}(1)$ attention instead of $\mathcal{O}(T^2)$ recomputation.

\subsection{Cross-Domain Generalisation}

The ATLAS and CAMEL datasets expose the model to qualitatively different
float32 entropy regimes, providing a natural cross-domain test:

\begin{itemize}[leftmargin=1.2em,itemsep=2pt]
  \item \textbf{ATLAS}: exponent bytes cluster near
        $[\texttt{0x3e}, \texttt{0x40}]$ (physics observables normalised
        to $\mathcal{O}(1)$); mantissa bytes are near-uniform.
  \item \textbf{CAMEL}: density and mass span $>$6 orders of magnitude,
        producing a multi-modal exponent distribution. Electron abundance
        is bounded in $[0,1]$, so the sign byte is \emph{always zero}
        for that field---a structural regularity invisible to a single
        shared embedding table but trivially modelled once byte position
        is known via TDT.
  \item \textbf{CAMEL positions}: simulation-box coordinates fill the
        full float32 range, yielding near-uniform exponent bytes---the
        reverse of ATLAS, where exponents are tightly clustered.
\end{itemize}

TDT's per-position tables inherently capture this field-type byte structure
without domain-specific tuning. LTE's importance scorer naturally
concentrates the memory budget on sudden density spikes, velocity
discontinuities, and phase boundaries in CAMEL, analogous to
exponent-change boundaries in ATLAS. Both behaviours emerge from the same
trained module with no dataset-specific hyperparameters, suggesting the
design is domain-agnostic for IEEE-754 scientific float32 data.

\section{Limitations and Future Work}
\label{sec:limitations}
% -----------------------------------------------------------------------

\begin{itemize}[leftmargin=1.2em,itemsep=2pt]
  \item \textbf{Convergence results pending.} Final BPD at 300\,k steps
        is not yet available; Table~\ref{tab:bpd} reports early-training
        results only.

  \item \textbf{Arithmetic coding speed.} The \texttt{torchac} library
        performs arithmetic coding on CPU. For large files,
        encoding/decoding is the bottleneck, not inference.

  \item \textbf{Multi-domain evaluation pending.} CAMEL results at
        convergence and evaluations on ERA5, LIGO, OpenFWI, and Planck
        are not yet complete; Table~\ref{tab:bpd_multi} reports
        early-training ATLAS numbers only.

  \item \textbf{Byte-order sensitivity.} The TDT assumption $t \bmod 4 =
        \text{byte position in float32}$ requires little-endian input with
        no field interleaving. Structured HDF5 datasets with multiple
        dtypes require field-aligned chunking.

  \item \textbf{Quantisation for weight compression.} ZipNN stores
        mantissa bytes raw. Float16/BF16 quantisation of weights before
        ZipNN compression may further reduce the MDL cost; we leave this
        for future work.
\end{itemize}

% -----------------------------------------------------------------------
\section{Conclusion}
\label{sec:conclusion}
% -----------------------------------------------------------------------

We presented \textsc{Vortex-Codec}, a neural lossless compression pipeline
for IEEE-754 float32 scientific data that combines five targeted architecture
improvements---TDT, LTE, Infini-$\beta$, CATWrapper, and ZipNN---into a
practical training and inference harness. By explicitly exploiting the
structured entropy profile of float32 byte streams and maintaining a
compressed long-range memory, the model matches gzip compression after only
3\% of the planned training budget on 200\,MB of ATLAS FTAG b-tagging jet
data. We further demonstrate the approach on CAMEL IllustrisTNG
cosmological simulation data, a fundamentally different float32 domain, and
identify four additional public benchmarks---ERA5, LIGO O3, OpenFWI, and
Planck 2018 CMB---as a standardised evaluation suite for future neural
scientific compression research. The full training runs are ongoing; we
expect the model to surpass lzma-6 (4.74\,BPD) on ATLAS and to show
consistent BPD improvements over classical baselines across the benchmark
suite. Code, configs, and all experiment harnesses are publicly available.
